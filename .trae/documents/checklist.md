# Checklist Kualitas Proyek

## Desain & UI/UX
- [ ] Antarmuka menggunakan gaya Glassmorphism yang konsisten.
- [ ] Tipografi menggunakan Inter dengan hierarki yang jelas.
- [ ] Skema warna mengikuti desain sistem (Deep Purple & Sky Blue).
- [ ] Aplikasi responsif sepenuhnya (Mobile, Tablet, Desktop).
- [ ] Animasi transisi halaman halus.

## Fungsionalitas
- [ ] Pendaftaran dan Login berfungsi dengan benar melalui Firebase.
- [ ] Semua operasi CRUD (Tugas, Acara, Catatan, Transaksi, Kebiasaan) berjalan real-time.
- [ ] Filter dan pengurutan pada daftar tugas berfungsi.
- [ ] Grafik keuangan dan progres kebiasaan menampilkan data yang akurat.
- [ ] Widget cuaca dan berita mengambil data dari API eksternal.

## Teknis & Performa
- [ ] Manajemen state menggunakan Zustand dengan efisien.
- [ ] Kode terorganisir dalam komponen-komponen kecil (< 200 baris).
- [ ] Penggunaan TypeScript untuk keamanan tipe data.
- [ ] Tidak ada error linter atau konsol yang signifikan.
- [ ] Load time halaman di bawah 3 detik.
