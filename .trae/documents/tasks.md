# Daftar Tugas Pengembangan (Tasks)

## Tahap 1: Inisialisasi Proyek
- [ ] Inisialisasi proyek React dengan Vite dan Tailwind CSS.
- [ ] Konfigurasi struktur folder (src/components, src/pages, src/hooks, dll.).
- [ ] Instalasi dependensi (Zustand, Lucide React, Framer Motion, Recharts, Firebase).

## Tahap 2: Konfigurasi Firebase & Autentikasi
- [ ] Setup konfigurasi Firebase SDK.
- [ ] Implementasi hook autentikasi dengan Firebase Auth.
- [ ] Pembuatan halaman Login dan Register.
- [ ] Proteksi rute (Hanya pengguna login yang bisa akses dashboard).

## Tahap 3: Tata Letak Dasar (Layout) & Navigasi
- [ ] Implementasi Sidebar dan Navbar yang responsif.
- [ ] Setup React Router untuk navigasi antar fitur.
- [ ] Implementasi tema dasar (Glassmorphism).

## Tahap 4: Implementasi Fitur Core
- [ ] **Dashboard Home**: Widget cuaca, berita, dan ringkasan statistik.
- [ ] **Manajemen Tugas**: CRUD tugas dengan Firestore.
- [ ] **Kalender & Acara**: Integrasi kalender dan manajemen acara.
- [ ] **Catatan**: Fitur memo dengan sistem tag.
- [ ] **Pelacak Keuangan**: Input transaksi dan visualisasi grafik Recharts.
- [ ] **Pelacak Kebiasaan**: Checklist harian dan heatmap progres.

## Tahap 5: Poles & Finalisasi
- [ ] Penambahan animasi transisi dengan Framer Motion.
- [ ] Pengujian responsivitas di berbagai ukuran layar.
- [ ] Optimasi performa dan pembersihan kode.
